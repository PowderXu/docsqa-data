Prisma Client provides features that are typically either not achievable with particular databases or require extensions. These features are referred to as *polyfills*. For all databases, this includes:

-   Initializing ID (source link: `/orm/v7/prisma-schema/data-model/models#defining-an-id-field`) values with `cuid` and `uuid` values
-   Using `@updatedAt` (source link: `/orm/v7/prisma-schema/data-model/models#defining-attributes`) to store the time when a record was last updated

For relational databases, this includes:

-   Implicit many-to-many relations (source link: `/orm/v7/prisma-schema/data-model/relations/many-to-many-relations#implicit-many-to-many-relations`)

For MongoDB, this includes:

-   Relations in general (source link: `/orm/v7/prisma-schema/data-model/relations`) - foreign key relations between documents are not enforced in MongoDB
