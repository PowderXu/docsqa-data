### Reference answer to review

Judge the normalized benchmark answer below. The original community answer is retained at the end for provenance, not as a second item to score.

```text
A repository is the GitHub workspace where your project’s files and change history are stored.

To create one on GitHub:

1. Sign in to GitHub.
2. In the upper-right corner, select the **+** menu, then click **New repository**.
3. In **Owner**, select your personal account.
4. Enter a name in **Repository name**.
5. Optionally enter a short project description.
6. In **Choose visibility**, select **Public** if you want the project to be publicly accessible.
7. Select **Add README**. This creates a starting file where you can describe the project.
8. Leave the `.gitignore` and license options unchanged for now unless you specifically need them.
9. Click **Create repository**.

Your new repository will then be available on GitHub, with the README as its initial file.
```
