### Question

```text
Github Login - Can't Access Email
Select Topic Area
Question
I'm trying to log in to my work github account and it's sending me a verification code to the work email address that can no longer receive emails (the company switched to a different email provider). I don't have 2FA setup, and I don't see any other way to log in. How can I deal with this situtation? I've already submitted a github support ticket, I just want to see if there's any advice I can get while I wait for them to get back to me.
```

### Reference answer to review

Judge the normalized benchmark answer below. The original community answer is retained at the end for provenance, not as a second item to score.

```text
GitHub Support is the appropriate channel for this account-access problem, so the ticket you already submitted is the correct next step. In any follow-up, explain that the verification code is being sent to the former work email address and that the company changed email providers.

To help Support investigate, include the affected GitHub username or account details, the exact login or verification error, the steps that produce it, the existing ticket number, and screenshots showing the full page URL with sensitive information redacted. Select an email address you can use for Support correspondence in the ticket form. If you cannot sign in to the Support portal, its ticket-creation procedure includes a “Can’t sign in?” option with an email-verification process.
```
